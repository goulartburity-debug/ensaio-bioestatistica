# Ensaio — guia didático de Bioestatística

Projeto de monitoria de Bernardo Goulart Burity, baseado nos materiais da Profa. Ana Paula Madureira e nas referências acadêmicas vinculadas na interface.

Versão em avaliação: planejamento experimental, exemplos explicados, glossário e orientação de análises. O site não executa análises estatísticas nem recebe tabelas de dados. Respostas são guardadas somente no navegador do visitante.

## Publicação no GitHub Pages

1. Envie os arquivos extraídos deste pacote diretamente à raiz do repositório; index.html deve ficar ao lado de app.mjs e styles.css. Não envie o ZIP.
2. Abra Settings > Pages.
3. Em Source, escolha Deploy from a branch.
4. Selecione a branch main e a pasta / (root), depois Save.
5. Aguarde a publicação e use Visit site.

Os módulos JavaScript precisam ser servidos por HTTP(S); abrir index.html diretamente por duplo clique não substitui a publicação.

## Atualizações

Envie os arquivos modificados às mesmas posições no repositório. O endereço publicado permanece o mesmo. Antes de substituir a versão, preserve o histórico de alterações e confira os testes do projeto de desenvolvimento.
